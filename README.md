# DIO----Modelo-de-oficina-SQL

Modelo de funcionamento de uma oficina, onde o cliente pode levar seu veiculo para revisao ou conserto.
O veiculo e submetido a uma equipe, composta por N funcionarios, e essa equipe emite uma OS.
A OS é composta por um serviço ou mais, bem como um serviço é composto por uma peça oou mais.
